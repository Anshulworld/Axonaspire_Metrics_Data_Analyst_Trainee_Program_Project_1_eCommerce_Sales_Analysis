# Axonaspire_Metrics_Data_Analyst_Trainee_Program_Project_1_eCommerce_Sales_Analysis
# 🛒 eCommerce & Superstore Retail Sales Analysis

An end-to-end exploratory data analysis (EDA) and interactive business intelligence project evaluating retail sales performance, category profitability, and customer spending behavior. Built as **Project 1** for the **Axonaspire Metrics Data Analyst Trainee Program**.

---

## 🎯 Project Objectives
- Clean and preprocess raw eCommerce transactional data for accurate reporting.
- Identify revenue trends, seasonal fluctuations, and top-performing product categories.
- Pinpoint the top 10 revenue-generating products and evaluate customer spend patterns.
- Deliver both static visual reports and an interactive HTML sales dashboard for stakeholders.

---

## 📂 Repository Structure

| File / Folder | Description |
| :--- | :--- |
| `Project_1_Superstore_Retail_Analysis.ipynb` | Main Jupyter Notebook containing data cleaning, EDA, statistical summaries, and chart generation. |
| `Project_1_Interactive_Sales_Dashboard.html` | Standalone interactive HTML dashboard for dynamic sales and KPI exploration. |
| `Kaggle_Super_Store_Dataset.csv` | Raw transactional dataset sourced from Kaggle. |
| `superstore_cleaned.csv` | Processed and cleaned dataset ready for analysis and visualization. |
| `1_sales_trends_line_chart.png` | Time-series visualization highlighting historical sales trends and growth patterns. |
| `2_category_distribution_bar_chart.png` | Comparative breakdown of sales performance across product categories. |
| `3_top_10_products_table.csv` | Exported summary table of the top 10 highest-performing products. |
| `4_customer_spend_scatter_plot.png` | Scatter analysis examining customer spend distribution and order relationships. |
| `HTML_Dashboard_PNG/` | Folder containing static preview captures of the interactive dashboard. |

---

## 🛠️ Tools & Technologies
- **Programming & Analysis:** Python (Pandas, NumPy)
- **Visualization:** Matplotlib, Seaborn, Plotly / Interactive HTML
- **Environment:** Jupyter Notebook

## 📊 Key Analytical Outputs

* **Sales Trends Over Time:** Tracks revenue trajectory to uncover peak periods and slowdowns (`1_sales_trends_line_chart.png`).
